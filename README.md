# QuantumGame

Unity project for experiments based on the Quantum engine.

## Repository

This repository tracks Unity source assets and project settings. Generated Unity
folders such as `Library`, `Temp`, `Logs`, and local `UserSettings` are ignored.

## Setup

1. Open the project folder in Unity.
2. Let Unity restore packages from `Packages/manifest.json`.
3. Commit source assets, package manifests, and project settings.
